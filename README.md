# Dashboard workshop starter

The starting point for **Building a Live Data Quality Dashboard with Claude Code**, a hands-on
workshop by [Exagrow](https://exagrow.com) for DAMA-MN.

There is almost nothing here on purpose. You and Claude build the dashboard together during
the workshop. The important file is [`CLAUDE.md`](CLAUDE.md): it tells Claude how to work in
this project, including how to keep your API key safe and how to back up every change to
GitHub as you go.

## Before the workshop

1. A Claude Pro account, and Claude Desktop installed.
2. Git installed.
3. A free GitHub account.
4. A personal laptop, or a work laptop where you have local admin rights.

## During the workshop

1. Click **Use this template**, then **Create a new repository**, to make your own copy in
   your GitHub account.
2. In Claude Desktop, open the Code tab and clone your new repository.
3. Tell Claude what you want to build. We will do the rest together, step by step.

## What you will leave with

- A live dashboard on a public URL, with a test copy (`dev`) and a real copy (`prod`).
- An API key you created, stored the safe way.
- A GitHub history of every step, so nothing you built can be lost.
